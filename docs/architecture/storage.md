# Storage architecture

See [ADR-0002](../adr/0002-storage-provider-abstraction.md), [ADR-0004](../adr/0004-enums-as-check-constraints.md) and [ADR-0005](../adr/0005-tenant-isolation.md).

## Where data lives

| Data | Store | Notes |
| --- | --- | --- |
| Original files and revisions | Google Drive (user's account) | Source of truth for content |
| Metadata, tags, collections, jobs, audit, chat, agent traces | PostgreSQL | Backed up |
| Extracted text, chunks | PostgreSQL | Needed to rebuild vectors |
| Embeddings | Qdrant | Derived and rebuildable; payload always includes `user_id` |
| Queue, worker heartbeat | Redis | AOF-persisted; job truth is in PostgreSQL |
| OAuth tokens | PostgreSQL, encrypted (`encrypted_access_token`, `encrypted_refresh_token`) | Never sent to clients. `token_key_version` supports key rotation |

## Schema overview (migration `0001`)

- **Identity:** `users`, `user_sessions` (refresh-token hashes and rotation chain), `oauth_accounts`, `storage_connections`, `api_keys` (hashes only).
- **Files:** `folders`, `files`, `file_versions`, `file_metadata` (key/value with `source` ∈ system/ai/user, `confidence`, `source_page`, `is_confirmed`), `tags`, `file_tags` (suggested/confirmed/rejected), `collections`, `collection_files`.
- **Processing:** `document_processing_jobs` (idempotency key, attempts, progress, sanitized errors), `document_extracted_content` (per page, native or OCR, bounding boxes, confidence), `document_entities` (knowledge-graph seed), `document_summaries`, `document_chunks` (page range, section, content hash, GIN full-text index), `embedding_records`.
- **AI:** `ai_conversations` (scope), `ai_messages` (citations and a full trace), `agent_runs`, `agent_steps`, `agent_tool_calls` (confirmation state), `search_history`.
- **System:** `audit_logs` (append-only; `user_id` is SET NULL so the trail survives account deletion), `security_events`, `notifications`, `sync_jobs`, `sync_events`, `feature_flags` (global or per-user, `NULLS NOT DISTINCT`).

## Conventions

- UUID primary keys (`gen_random_uuid()`), `created_at`/`updated_at` as `timestamptz`, and soft delete (`deleted_at`) where users expect to restore.
- Deterministic constraint names (naming convention in `saige_api.db.base`), all ≤ 63 characters.
- MIME type is the server-detected value, never the client's claim.
- AI-derived values always carry provenance (`source = ai`) and stay unconfirmed until the user confirms them.

## Traceability chain

```text
AI answer → ai_messages.citations → document_chunks (page_start/page_end) → files → storage_file_id (Drive)
```

## Knowledge graph extension point

`document_entities` holds typed entities per document. A future `entity_relations` table (subject entity, predicate, object entity, evidence chunk) can be added without changing existing tables. Graph traversal can stay in PostgreSQL (recursive CTEs) until a dedicated graph store is justified.
