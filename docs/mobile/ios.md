# iOS app

SwiftUI, Swift 6 (strict concurrency), iOS 17+. The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `apps/ios/project.yml` and is never committed.

## What's built

- Tab app: **Home** (quick actions, live server status, setup checklist), **Files**, **Search**, **Ask Saige**, **Settings**.
- **App Lock:** Face ID / Touch ID with passcode fallback. On by default; locks whenever the app goes to the background.
- **Privacy shield:** content is hidden in the app switcher and while the app is inactive.
- **Networking:** typed `APIClient` (async/await, typed throws), ephemeral session with no disk cache, `X-Request-ID` on every request, and server error envelopes surfaced as `APIError.server`.
- **Configuration:** server URL from xcconfig into Info.plist (`SaigeAPIBaseURL`). Release builds refuse non-HTTPS URLs.
- **Honest UI:** every capability that isn't built yet shows the phase it ships in. Nothing is uploaded or sent.
- Tests: XCTest (config, API decoding incl. 503 readiness and error envelopes, readiness copy, feature registry) and XCUITest (tab navigation, quick-action notice).

## Requirements

- A Mac with **Xcode 16 or newer** (iOS cannot be built on Windows or Linux).
- Homebrew (to install XcodeGen).
- To install on your iPhone: a free Apple ID is enough for personal installs (profiles expire after 7 days). A paid Apple Developer Program membership ($99/yr) gives 1-year profiles, ad-hoc distribution and TestFlight.

## First-time setup

```bash
cd apps/ios
make bootstrap            # installs xcodegen, creates Config/Local.xcconfig, generates the project
open SaigeVault.xcodeproj
```

Edit `Config/Local.xcconfig` (git-ignored):

```text
SAIGE_DEVELOPMENT_TEAM = <your Team ID>       # Xcode → Settings → Accounts
SAIGE_BUNDLE_ID = com.<yourname>.saigevault   # must be globally unique
SAIGE_API_BASE_URL = http:$(SLASH)$(SLASH)192.168.1.20:8000   # your Mac's LAN IP for a physical iPhone
```

(`$(SLASH)` is needed because `//` starts a comment in xcconfig files.)

## Run on your iPhone

1. Start the backend on your Mac, reachable from your Wi-Fi: `API_BIND=0.0.0.0 docker compose up -d`. By default the API binds to `127.0.0.1` only. Use LAN binding only on a trusted home network; for anything else, deploy behind HTTPS ([cloud.md](../deployment/cloud.md)). CORS does not apply to native apps.
2. Connect the iPhone by cable (or the same Wi-Fi with wireless debugging), and trust the computer.
3. On the iPhone, enable **Settings → Privacy & Security → Developer Mode** (iOS 16+) and restart.
4. In Xcode, select the **SaigeVault** scheme and your iPhone, then press **Run** (⌘R).
5. First launch with a free account: **Settings → General → VPN & Device Management → trust your developer certificate**.
6. Allow **Local Network** access when prompted (needed to reach your Mac).

## Command-line builds

```bash
make test          # unit + UI tests on a simulator (CODE_SIGNING_ALLOWED=NO)
make archive       # Release archive (signed with your team)
make ipa-dev       # export .ipa for your registered devices
make ipa-adhoc     # ad-hoc export (paid account)
```

`ExportOptions/TestFlight.plist` exports for App Store Connect / TestFlight internal testing. Public App Store release is not required.

## CI

`.github/workflows/ci.yml` → job `ios` runs `apps/ios/scripts/ci-test.sh` on `macos-15`. It generates the project, picks the newest iPhone simulator, and runs all tests without code signing.
